# Senior Frontend Interview Study Plan

This study plan outlines three structured timelines (30-day, 60-day, 90-day) designed to help you prepare systematically for L6/L7 senior frontend roles.

---

## 📅 30-Day Plan (High Intensity)

Recommended if you have an interview in 4 weeks. Requires 2-3 hours daily.

- **Week 1: JS Engines, Closures, Async, & CSS Mechanics**
  - Focus: JavaScript Event Loop, memory allocation, closures, scoping, prototypes, cascade, specificity, Flexbox/Grid, CSS variables.
  - Deliverable: Finish modules JS-001 to JS-005, CSS-001 to CSS-003.
- **Week 2: Browser Engine & React Architecture**
  - Focus: Critical Rendering Path (CRP), Reflow/Repaint, DOM/BOM, React Fiber, Hooks internals, stale closures, rendering optimizations.
  - Deliverable: Finish modules Browser-001 to Browser-003, React-001 to React-004.
- **Week 3: System Design, Next.js RSCs, & Performance**
  - Focus: Virtualization, infinite scroll, dashboard syncing, Monorepos, Core Web Vitals, memory profiling, bundle optimizations, SSR/RSC dynamics.
  - Deliverable: Finish modules System-001 to System-004, Performance-001 to Performance-003.
- **Week 4: Testing, Debugging, & Behavioral Story Bank**
  - Focus: MSW, custom hook testing, debug loops, memory leaks, STAR story bank refinement, and verbal mock interviews.
  - Deliverable: Finish Testing-001, Debugging-001, and all behavioral stories.

---

## 📅 60-Day Plan (Standard Pace)

Recommended for a balanced preparation. Requires 1 hour daily.

- **Days 01–15: Core Languages (JS / TS / CSS)**
  - Group topics: Scope, Event Loop, Prototypes, Modules, Types, CSS specificity, Layouts.
- **Days 16–30: React Core & Modern Frameworks**
  - Deep-dive: Fiber, Hooks lifecycles, state colocation, Zustand, RSCs, Hydration.
- **Days 31–45: Browser Architecture & Systems Design**
  - Group topics: HTTP cache, storage, CORS, virtual lists, dashboards, auth flows.
- **Days 46–55: Performance, Testing, & Diagnostics**
  - Focus: Chrome DevTools performance profiling, memory dumps, RTL/MSW.
- **Days 56–60: Final Review & Mock Audits**
  - Mock interviews, Story Bank rehearsal, and debugging challenges.

---

## 📅 90-Day Plan (Comprehensive Learning)

Recommended for long-term growth and transition into a tech lead mindset. Requires 45 minutes daily.

- **Month 1: Underlying Foundations & Engines**
  - First 2 weeks: V8 mechanics, stack/heap allocation, event loop, prototypes.
  - Last 2 weeks: Browser paint pipeline, composite layers, box model, CSS Grid algorithms.
- **Month 2: React Ecosystem & Large-Scale System Design**
  - First 2 weeks: React Fiber reconciler, scheduling loop, custom state managers.
  - Last 2 weeks: Frontend System Design (Micro-frontends, component libraries, Monorepos, API contracts).
- **Month 3: Performance, Testing, & Soft Skills**
  - First 2 weeks: Web Vitals, memory profiles, test pyramids, MSW.
  - Last 2 weeks: Debugging scenarios, behavioral bank, leadership mock sessions.

---

## 🔄 Daily 45-Minute Routine

To maximize retention:
1. **00m - 10m (Active Reading)**: Read the Theory markdown. Write down the core V8/Browser mechanic in a notebook.
2. **10m - 25m (Self-Assessment)**: Complete the Quiz. Do not cheat—reason through the execution trace.
3. **25m - 45m (Coding/Debugging)**: Solve the Practical problem. Ensure it passes the edge cases and fits within time limits.

---

## 🏕️ Weekend Deep-Practice Routine (2-3 Hours)

On Saturdays or Sundays, perform a "deep practice" block to consolidate learning:

- **Hour 1: Re-build from Scratch**
  - Choose one complex utility (e.g., custom promise, deep copy, virtual list, debounce) and code it on a blank screen without checking notes.
- **Hour 2: Real-world Debugging**
  - Simulate a production bug. Take a practical debugging exercise, write failing unit tests, identify the root cause using profiling mindsets, and write a prevention checklist.
- **Hour 3: Architectural Review**
  - Draw component architecture diagrams for one of the System Design modules (e.g., Infinite Scroll or Dashboard State Syncing) on a whiteboard or design tool.

## 🎭 Mock Interview Strategy

1. **Find a Peer or Platform**: Use platforms like Pramp, interviewing.io, or mock with a senior peer.
2. **Verbal Execution**: Practice talking for 5 minutes about a complex project without getting bogged down in minor details (use the structure in Coaching -> Project Deep Dive).
3. **Clarification Phase**: In mock codings, spend the first 5 minutes purely asking clarifying questions about inputs, outputs, performance thresholds, and scale.
