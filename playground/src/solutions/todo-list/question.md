# Todo List

You are given some existing HTML for a Todo List app. Add the following functionality to the app:

- **Add tasks**: Add new tasks on clicking the "Submit" button.
- **Clear input**: The `<input>` field should be cleared upon successful addition.
- **Delete tasks**: Remove tasks from the Todo list upon clicking the "Delete" button next to a task.

### Notes

- The focus of this question is on functionality, not styling. There is no need to write any custom CSS.
- You may modify the markup (e.g., adding IDs, data attributes, replacing tags, etc.), but the final result should remain visually consistent.
- Think about ways to improve the user experience of the application and implement them (bonus points in interviews for adding useful enhancements).
